AHT20 temperature / humidity sensor
Raspberry Pi 5 uses the AHT20 via I²C. The I²C bus pins are fixed by the hardware — no configuration required.
Connect: SDA → GPIO 2 (Pin 3)  ·  SCL → GPIO 3 (Pin 5)  ·  VCC → 3.3 V (Pin 1)  ·  GND → GND (Pin 6)
{% else %} {# ── Pi 3 / 4 (or unknown): DHT22 bit-bang OR AHT20 I²C ── #} {% if is_admin %}
{% endif %}
Pi 3 / Pi 4 supports both DHT22 (bit-bang) and AHT20 (I²C).
AHT20 is recommended — more reliable and uses fixed I²C pins (GPIO 2 SDA, GPIO 3 SCL). Set temp_sensor_type: aht20 in config.yaml to use it without any GPIO config here.
Only used when temp_sensor_type: dht22 is set in config.yaml. Connect the DHT22 DATA wire to the selected GPIO pin.
